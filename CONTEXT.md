# bareclock glossary

| Term | Meaning |
| --- | --- |
| Main clock | The large time and date display |
| Clock style | A visual clock face, such as Flip or Halo |
| Theme | A color palette, separate from the clock style |
| World clock | A smaller time display for a saved city |
| World clock rail | The saved clocks on the right, or below the main clock on narrow screens |
| Main timezone | The timezone shown by the main clock, following the device by default |
| Saved city | A place stored with its own identity and timezone; different cities can share a timezone |
| Clock swap | Exchanging a world clock with the main clock, moving the previous main city into its rail slot |

See [architecture](docs/architecture.md) for implementation details.
